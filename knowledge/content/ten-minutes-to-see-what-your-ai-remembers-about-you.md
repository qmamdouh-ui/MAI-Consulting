Claude and Gemini both keep notes about you now, and most people have never read them. A wrong or stale note, such as an old job title or a project that closed, quietly shapes every answer until you correct it. Reading the notes takes about ten minutes (as of November 2026).

*Once a month, open your assistant's memory, read what it kept, delete what is wrong, and decide which chats it should never learn from.*

**Try it now.** In Claude, open Settings > Your Claude and click Manage next to "Your memory" (in the older layout it is Settings > Memory). In Gemini, open Settings & help > Personal context. Read every item and correct the first one that is no longer true.

## Claude: memory is on by default, and you can read it

Anthropic's memory help page says memory is on by default for Free, Pro, Max and Ultra plans. Everything Claude remembers is listed as separate topics that you can read, edit and delete.

- **On Team and Enterprise it works differently.** Owners control whether memory is available, and it stays off for each member until that member turns it on.
- **Check the sensitive-topics setting.** There is a switch called "Include sensitive topics in memory". Decide on purpose whether Claude should keep that kind of information.
- **Some things are never saved.** The page lists government ID numbers, criminal history, financial account numbers and immigration status as information Claude does not save to memory even if you ask.

## Gemini: two kinds of memory, in one place

Gemini keeps two kinds of memory. Knowing which is which tells you where to look when an answer seems to know something it should not.

- **Memory of past chats.** Open gemini.google.com, click Settings & help, then Personal context, and turn Memory on or off. Google's page says it needs Keep Activity on, you must be 18 or over, and it is not available on work, school or supervised Google Accounts.
- **Saved info.** The things you asked Gemini to remember are stored in Personal context too. Click Add to write an item, or More next to an existing one to Edit or Delete it.
- **See when it was used.** When saved info shapes an answer, "Your saved info" usually appears under "Sources and related content" at the bottom of the response, although Google says the label can occasionally be wrong. For past chats, Google's page suggests asking: "Did you use any info from past chats?"

> Memory you never read is a set of assumptions about you that nobody is checking.

## Read it, then prune it: ten minutes, once a month

Reading the memory is the whole habit. The tools make it easy. Nothing reminds you to do it.

- **In Claude: read each topic.** Select a topic to read it, use the edit icon to correct it, or choose Delete. You can also tell Claude in a chat what to remember, change or forget. Look for the job you left, the project that closed, the assumption about your audience that was true once.
- **Deleting a chat does not delete what Claude learned from it.** Anthropic's page says the memory entries generated from a conversation are not removed when you delete it. Pause memory keeps what is stored but stops using and adding to it. Reset memory permanently deletes all memories, project memories included.
- **In Gemini, memory follows the chats.** To make Gemini forget something from past chats, Google's page says to delete all chats that contain it from Gemini Apps Activity, and warns of a short delay before Gemini stops using it. If a connected app is involved, you also need to disconnect it.

## Keep some chats out of it from the start

Pruning fixes what is already stored. The better habit is deciding beforehand which conversations should leave nothing behind: a personal question on a work laptop, a one-off task for a colleague, a draft you are only testing.

- **Claude, one chat at a time.** In a new chat outside a project, click the ghost icon at the top right to go incognito. Or click "+" and turn Memory off before your first message, and that chat stays in your history but does not feed memory. On Team and Enterprise, Anthropic notes that incognito chats are still included in organisation data exports.
- **Claude, one project at a time.** Each project has its own memory. To keep a project from also drawing on your account memory, turn off "Use account memory" on the project's page.
- **Gemini's Temporary chat.** Click Temporary chat next to New chat on gemini.google.com. Google says it does not appear in your Gemini Apps Activity or recent chats, and it does not use or save personal memory. Google's Privacy Hub adds that temporary chats are still retained for 72 hours. It is not available on work or school accounts.

## The bottom line

**Memory makes an assistant more useful only while it is right, so read it monthly and keep the chats that should leave no trace out of it.**
