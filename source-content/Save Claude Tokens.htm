    <div class="two-col">

      <div>

        <h3 style="font-size:1.15rem;font-weight:700;color:var(--txt);margin-bottom:.75rem;">What is CLAUDE.md?</h3>

        <p style="font-size:.9rem;line-height:1.75;color:var(--charcoal);margin-bottom:1rem;">

          <code style="background:var(--blue-light);padding:.15rem .4rem;border-radius:4px;font-size:.82rem;color:var(--blue);">CLAUDE.md</code> is a Markdown file Claude reads at the start of every session within a project or directory. It acts as standing instructions — your organization's style guide, terminology, prohibited behaviors, output formats, and domain context, all loaded automatically.

        </p>

        <p style="font-size:.9rem;line-height:1.75;color:var(--charcoal);">

          In Claude Code, CLAUDE.md files are hierarchical: a root-level file sets global defaults, while subdirectory files add context for specific modules or workstreams. This means a legal team and an engineering team can operate with different rules without manual switching.

        </p>

 

        <div class="callout" style="margin-top:1.5rem;">

          <p><strong>Practical tip:</strong> Put your most-used constraints in CLAUDE.md rather than in every prompt. Anything you repeat more than 3 times per week — response format, tone, citation rules, domain vocabulary — belongs there.</p>

        </div>

      </div>

 

      <div>

        <h3 style="font-size:1.15rem;font-weight:700;color:var(--txt);margin-bottom:.75rem;">CLAUDE.md Structure</h3>

        <div class="code-block">

<span class="cmt"># CLAUDE.md — Project: Consulting Engagements</span>

 

<span class="key">## Role</span>

<span class="str">You are a strategy analyst at M.A.I. Consulting.

Responses must be professional, evidence-based,

and free of hedging language.</span>

 

<span class="key">## Output Rules</span>

<span class="str">- Use Markdown tables for comparisons

- Keep section headings concise

- Never add preamble before answers

- Cite sources inline as [Source, Year]</span>

 

<span class="key">## Domain Context</span>

<span class="str">Client industry: Public sector + NGOs

Primary frameworks: Logic models, ToC, SWOT

Internal acronyms: ToR = Terms of Reference</span>

 

<span class="key">## Prohibited</span>

<span class="str">- Do not invent data

- Do not recommend tools without evidence

- Do not use the word "leverage"</span>

        </div>

      </div>

          <p>If you send a long system prompt or large document repeatedly (e.g., a knowledge base), use Anthropic's <strong>prompt caching</strong> API feature. Cached tokens cost 90% less per re-use. Cache invalidates after 5 minutes of inactivity by default.</p>

          <div class="badge-row">

            <span class="badge">API Only</span>

            <span class="badge">High Impact</span>

          <h3>Model Selection</h3>

          <p>Don't use Opus for every task. Claude Haiku handles classification, simple extraction, and short Q&A at a fraction of the cost. Sonnet covers most complex workflows. Opus is justified for nuanced reasoning and long-form drafting where quality genuinely matters.</p>

          <div class="badge-row">

            <span class="badge">API + UI</span>

            <span class="badge">Structural</span>

          <h3>Context Trimming</h3>

          <p>Conversation history grows with every turn. In long sessions, early exchanges often add noise rather than signal. Periodically summarize the conversation state and restart with a condensed context rather than sending the full thread each time.</p>

          <div class="badge-row">

            <span class="badge">Workflow</span>

        </div>

        <div class="card">

          <div class="card-icon">📌</div>

          <h3>Targeted System Prompts</h3>

          <p>Bloated system prompts — ones that try to cover every possible scenario — inflate input tokens on every call. Keep system prompts focused on the specific task. Put rarely-needed instructions in user messages or skill files loaded on demand.</p>

          <div class="badge-row">

            <span class="badge">Prompt Design</span>

          <p>Claude defaults to verbose responses unless told otherwise. Explicit instructions like "respond in under 150 words", "use a single sentence", or "no explanation, just the JSON" can cut output tokens by 50–70% on extraction and classification tasks.</p>
